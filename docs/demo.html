Reset every hour

Every hour the database goes back to the same sample data. New trips, edits, vehicles and tokens disappear; you stay logged in and simply see the fresh data.

If the login stops working, someone changed the password – it is back after the next reset.

Things to try

A short tour through the main features.

  1. Log a trip on your phone. Open the demo on your phone, tap “New trip” and use the GPS button for the current address.
  2. Edit a trip. Change a destination or odometer reading in the trip list, then look at the audit log.
  3. Switch vehicles. Pick the ID.3 in the navigation – every page then shows only its trips.
  4. Compare the 1% rule. Open the vehicle info page and see which method is cheaper, including the pre-tax check.
  1. Look back. The yearly history shows last year with a chart per month.
  2. Export. Download a year as CSV or PDF, or a JSON backup of the account.
  3. Go offline. Install the app on your home screen, switch to flight mode and log a trip – it is sent once you are back online.
  4. Try dark mode and English/German on the profile page.

Try the API

Create an API token on the account page, then log a trip from the command line – the same way Home Assistant does.

# log a trip for the Passat now; the odometer must be higher than the last trip's
curl -X POST \
  https://demo.example.com/api/trips \
  -H "Authorization: Bearer <API-TOKEN>" \
  -H "Content-Type: application/json" \
  -d '{
    "odometer_km": 99999,
    "destination": "API test",
    "trip_type": "business",
    "timestamp": "'"$(date -u +%Y-%m-%dT%H:%M:%SZ)"'",
    "vehicle_code": "DEMPKW"
  }'

Run your own demo

The repository contains everything needed for this demo in the demo/ folder: Compose stack, sample data and the reset container.

Setup

  1. Copy the folder demo/ to your Docker host.
  2. Configure. Set image tags, domain, DB_PASSWORD, JWT_SECRET and the demo passwords. 
    cp .env.example .env
  3. Start 
    docker compose up -d

How the reset works

A small PostgreSQL container loads seed.sql on start and then every RESET_INTERVAL_MINUTES (default 60), in a single transaction.

Reset right away:

docker compose exec reset /demo/reset.sh once

Details are in demo/README.md.
