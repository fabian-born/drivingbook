Home Assistant Integration – Fahrtenbuch
=========================================

Endpoint:   POST https://fahrtenbuch.home.fabianborn.net/api/fahrt
Auth:       Authorization: Bearer <API-TOKEN>  (Token unter Profil > API-Tokens erzeugen)

Verhalten vehicle_code
-----------------------
- Kein vehicle_code im Payload  -> Fahrt wird automatisch dem Standard-Fahrzeug zugeordnet
                                    (im Profil über "Als Standard" änderbar)
- vehicle_code: null            -> Fahrt bewusst ohne Fahrzeug-Zuordnung
- vehicle_code: "A9F82D"        -> Fahrt wird genau diesem Fahrzeug zugeordnet
                                    (Code steht im Profil neben dem jeweiligen Fahrzeug)

configuration.yaml
-------------------
rest_command:
  fahrtenbuch_fahrt_eintragen:
    url: "https://fahrtenbuch.home.fabianborn.net/api/fahrt"
    method: POST
    headers:
      Content-Type: "application/json"
      Authorization: "Bearer !secret fahrtenbuch_token"
    payload: '{"kmstand":{{ kmstand }},"ziel":"{{ ziel }}","fahrtart":"{{ fahrtart }}","timestamp":"{{ timestamp }}"}'

secrets.yaml
-------------
fahrtenbuch_token: "<DEIN-API-TOKEN>"

Aufruf (z. B. aus einer Automation)
-------------------------------------
service: rest_command.fahrtenbuch_fahrt_eintragen
data:
  kmstand: "{{ states('sensor.auto_kilometerstand') | int }}"
  ziel: "Home Assistant Update"
  fahrtart: "privat"
  timestamp: "{{ now().isoformat() }}"

Variante mit explizitem Fahrzeug
-----------------------------------
payload (rest_command):
'{"kmstand":{{ kmstand }},"ziel":"{{ ziel }}","fahrtart":"{{ fahrtart }}","timestamp":"{{ timestamp }}","vehicle_code":"{{ vehicle_code }}"}'

Aufruf:
service: rest_command.fahrtenbuch_fahrt_eintragen
data:
  kmstand: "{{ states('sensor.auto_kilometerstand') | int }}"
  ziel: "Home Assistant Update"
  fahrtart: "privat"
  timestamp: "{{ now().isoformat() }}"
  vehicle_code: "A9F82D"

km-Plausibilität
-------------------
Ist der neue kmstand kleiner als bei der vorherigen oder größer als bei der
folgenden Fahrt desselben Fahrzeugs, antwortet die API mit HTTP 409
(code: "KM_PLAUSIBILITY"). Mit "force": true im Payload wird das umgangen.
